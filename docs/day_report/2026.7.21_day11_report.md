Day 11：业务校验与异常处理完善

今日完成

1. 完善全局异常处理

新增 ConflictException（HTTP 409）
GlobalExceptionHandler 统一处理业务冲突异常
统一返回错误格式，提升 API 一致性

2. DTO 参数校验（Bean Validation）

为请求 DTO 添加参数校验：
@NotNull
@Positive
Controller 添加 @Valid
实现非法请求自动返回 400 Bad Request

3. Cart 模块业务规则
新增购物车业务校验：

商品不存在 → 404
商品已下架 → 409
餐厅暂停营业 → 409
购物车只能包含同一家餐厅商品 → 409

4. Checkout 二次校验（OrderService）
为了模拟真实外卖平台，下单前重新验证：

餐厅是否仍在营业
商品是否仍可售卖

避免用户加入购物车后，由于商家状态变化导致无效订单。

5. 订单状态机完善
新增订单状态流转校验：

重复修改为当前状态 → 409 Conflict
非法状态跳转 → 409 Conflict

保证订单生命周期符合业务规则。

完成全部核心接口测试：
