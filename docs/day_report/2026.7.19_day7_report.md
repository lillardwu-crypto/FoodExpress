## 12. 实现 JwtAuthenticationFilter

创建：

```text
security/jwt/JwtAuthenticationFilter.java
```

流程：

```text
Authorization Header

↓

Bearer Token

↓

解析 JWT

↓

验证 Token

↓

加载用户

↓

SecurityContextHolder

↓

放行请求
```

实现 OncePerRequestFilter。

---

## 13. SecurityConfig 集成 JWT Filter

完成：

```java

)
```
