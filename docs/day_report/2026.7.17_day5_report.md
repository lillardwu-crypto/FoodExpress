# 今日完成内容

## 一、完成购物车核心接口开发

实现了以下 RESTful API：

### 1. 添加商品到购物车

**POST**

```
/api/carts/{userId}/items
```

功能：

- 用户首次添加商品自动创建购物车
- 相同商品自动合并数量
- 返回最新购物车信息

---

### 2. 查看购物车

**GET**

```
/api/carts/{userId}
```

功能：

- 查询用户当前 ACTIVE 状态购物车
- 返回购物车所有商品
- 自动计算总金额

---

### 3. 修改购物车商品数量

**PUT**

```
/api/carts/items/{cartItemId}
```

功能：

- 修改指定 CartItem 数量
- 自动重新计算金额

---

### 4. 删除购物车商品

**DELETE**

```
/api/carts/items/{cartItemId}
```

功能：

- 删除指定商品
- 自动更新购物车金额
- 当前设计保留空购物车

---

# 二、完成业务逻辑实现

完成以下业务规则：

- 用户不存在校验
- 菜品不存在校验
- CartItem 不存在校验
- 数量必须大于 0
- 一个购物车只能属于一家餐厅
- 相同商品自动合并数量
- 自动计算商品小计（Subtotal）
- 自动计算购物车总金额（TotalPrice）

# 四、Repository 优化

新增自定义查询方法：

```java
findByUser_IdAndStatus()

findByCart_Id()

findByCart_IdAndMenuItem_Id()
```

优化购物车查询逻辑：

原实现：

```java
findAll()
    .stream()
    .filter(...)
```

优化后：

```java
findByCart_Id(cartId)
```

直接通过数据库完成过滤，减少无效数据查询，提高查询效率。

# 五、统一异常处理

新增异常类：

- BadRequestException
- ResourceNotFoundException

新增：

- ErrorResponse
- GlobalExceptionHandler

使用 `@RestControllerAdvice` 实现统一异常处理。

异常映射：

| 异常 | HTTP Status |
|------|-------------|
| BadRequestException | 400 Bad Request |
| ResourceNotFoundException | 404 Not Found |
| Exception | 500 Internal Server Error |

统一返回格式：

```json
{
    "timestamp": "...",
    "status": 404,
    "error": "Not Found",
    "message": "...",
    "path": "/api/..."
}
```
