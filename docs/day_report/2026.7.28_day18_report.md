# Completed

## 1. Installed Axios

Installed Axios to handle HTTP requests in React.

```bash
npm install axios
```

Created a reusable API client.

```javascript
import axios from "axios";

const apiClient = axios.create({
    baseURL: "http://localhost:8080/api",
});

export default apiClient;
```

---

## 2. Created API Layer

Created:

```
src/api/apiClient.js
src/api/restaurantApi.js
```

Implemented restaurant API.

```javascript
import apiClient from "./apiClient";

export async function getRestaurants() {
    const response = await apiClient.get("/restaurants");
    return response.data;
}
```

Separated API logic from UI components.

---

## 3. Refactored HomePage

Replaced mock data with asynchronous API requests.

Implemented:

- useState
- useEffect
- async / await

```javascript
const [restaurants, setRestaurants] = useState([]);

useEffect(() => {

    async function fetchRestaurants() {
        const data = await getRestaurants();
        setRestaurants(data);
    }

    fetchRestaurants();

}, []);
```

The restaurant list is now loaded from the backend after the page is rendered.

---

## 4. Solved CORS Issue

Encountered a browser CORS error when React attempted to access Spring Boot.

```
React (localhost:5173)
        ↓
Spring Boot (localhost:8080)
```

Configured global CORS support in `SecurityConfig`.

```java
http.cors(cors ->
        cors.configurationSource(corsConfigurationSource())
);
```

Added:

- Allowed Origin
- Allowed Methods
- Allowed Headers
- Credentials

Successfully enabled communication between the frontend and backend.


Configured CORS inside Spring Security.

---

## 2. RestaurantCard Data Model Mismatch

The original `RestaurantCard` component expected mock data fields:

- image
- rating
- category
- deliveryTime
- deliveryFee

Current backend returns:

- id
- name
- address
- phone
- status
- latitude
- longitude

**Temporary Solution**

Simplified `RestaurantCard` to display only the fields currently provided by the backend.
