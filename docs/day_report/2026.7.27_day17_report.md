## 3. Dynamic Rendering

Used React's `map()` function to render restaurant cards dynamically.

```jsx
<div className="restaurant-grid">
  {restaurants.map((restaurant) => (
    <RestaurantCard
      key={restaurant.id}
      restaurant={restaurant}
    />
  ))}
</div>
```

Benefits:

- Cleaner code
- Better scalability
- Easier maintenance
- Improved component reusability

## 5. Introduced API Layer

Created:

```text
src/api/restaurantApi.js
```

Current implementation:

```javascript
import restaurants from "../data/restaurants";

export function getRestaurants() {
    return restaurants;
}
```

Although the project still uses mock data, introducing an API layer establishes a production-style architecture.

Future backend integration will only require modifying `restaurantApi.js` without affecting page components.

---

## 6. Refactored HomePage

Updated `HomePage.jsx` to retrieve restaurant data through the API layer.

Previous approach:

```javascript
import restaurants from "../data/restaurants";
```

Current approach:

```javascript
import { getRestaurants } from "../api/restaurantApi";

function HomePage() {
    const restaurants = getRestaurants();

    ...
}
```

This decouples the page from the underlying data source.

---

## 7. Frontend Layered Architecture

Current architecture:

```text
HomePage
    │
    ▼
restaurantApi
    │
    ▼
restaurants.js (Mock Data)
    │
    ▼
RestaurantCard
```

Responsibilities:

| Layer | Responsibility |
|-------|----------------|
| HomePage | Organizes page layout and coordinates data |
| restaurantApi | Provides a unified interface for data access |
| restaurants.js | Temporary mock data source |
| RestaurantCard | Displays restaurant information |

This design mirrors the layered architecture used in the Spring Boot backend.
