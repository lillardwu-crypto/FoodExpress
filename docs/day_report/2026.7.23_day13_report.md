今日收获

今天最大的收获不是新增功能，而是完成了一次完整的安全性重构。

项目从依赖客户端传递 userId，升级为依赖 Spring Security + JWT 自动识别当前用户，实现了订单归属校验（Ownership Validation），使用户接口更加符合生产环境的安全设计。同时，整个重构覆盖了 Controller、Service、单元测试以及接口回归测试，形成了一次完整的开发闭环。

此外，通过完整验证订单状态机的合法与非法流转，也进一步保证了业务流程的可靠性。
