## 3. Bug 排查

今天定位并解决了一个比较典型的前后端联调问题。

### Bug

浏览器返回：

```
500 Internal Server Error
```

经过检查：

- Controller
- Service
- Entity
- Repository

均未发现问题。

最终查看 Spring Boot 日志发现：

```
Request method 'PUT' is not supported
```

原因：

前端请求方式仍然使用：

```
PUT
```

而后端接口定义为：

```
PATCH
```

修复：

```
apiClient.put(...)
```

修改为

```
apiClient.patch(...)
```

问题成功解决。
