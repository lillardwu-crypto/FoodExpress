## 2. Order Tracking Message
Implemented `OrderTrackingMessage`.

Fields:
- orderId
- status
- driverLatitude
- driverLongitude

**Result**
- Unified DTO for all real-time order updates.

## 3. OrderService WebSocket Broadcast
Modified `OrderService`.

Features:
- Broadcast order updates after every status change.
- Integrated `SimpMessagingTemplate`.
- Push updates to:
  - `/topic/orders/{orderId}`

Supported events:
- ACCEPTED
- PREPARING
- READY_FOR_PICKUP
- OUT_FOR_DELIVERY
- DELIVERED
- CANCELLED

**Result**
- Every order status update is immediately pushed to subscribed clients.
