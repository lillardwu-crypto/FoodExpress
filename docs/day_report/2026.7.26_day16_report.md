# 🐞 Issue Encountered

## React Router - Invalid Hook Call

Error:

```text
Invalid hook call.
Cannot read properties of null (reading 'useRef')
```

### Root Cause

`react-router-dom` was accidentally installed in the project root directory instead of the frontend project.

This caused multiple React instances to be loaded simultaneously.

### Solution

- Reinstalled `react-router-dom` inside:

```text
FoodExpress/frontend
```

- Cleared Vite cache
- Restarted the development server

Result:

✅ React Router works correctly.
