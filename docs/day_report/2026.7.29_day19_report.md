# Problems Encountered

## 1. Duplicate Menu Items

Restaurant Detail page displayed multiple identical menu items.

Example:

```
Cheese Burger

Cheese Burger

Cheese Burger

Cheese Burger
```

Root cause:

Repeated calls to

```http
POST /api/restaurants/{restaurantId}/menu-items/sample
```

created duplicate records.

---

## 2. Foreign Key Constraint

Attempting to delete duplicate menu items produced:

```text
Cannot delete or update a parent row:
a foreign key constraint fails
```

Reason:

Duplicate menu items were referenced by existing `cart_items`.

Solution:

- Removed dependent cart items
- Deleted duplicate menu items
- Verified only one menu item remained
