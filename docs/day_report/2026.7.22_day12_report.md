users

收获

今天完成了 FoodExpress 中一个关键的真实业务设计：

Order Address Snapshot（订单地址快照）

相比直接保存 Address 外键，地址快照可以保证：

用户修改地址不会影响历史订单
用户删除地址不会影响历史订单
配送记录永久保存下单时的真实地址

这是外卖、电商等订单系统中常见的设计模式，也是项目从课程 Demo 向工业级实现迈进的重要一步。
