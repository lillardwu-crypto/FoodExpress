# 1. 完成 MenuItem 与 Restaurant 的 JPA 关系

## MenuItem

```java
@ManyToOne(fetch = FetchType.LAZY)
@JoinColumn(name = "restaurant_id", nullable = false)
private Restaurant restaurant;
```

含义：

```text
多个 MenuItem
        ↓
属于
        ↓
一个 Restaurant
```

数据库层面：

```sql
menu_items

id
restaurant_id
name
price
...
```

其中：

```sql
restaurant_id
```

作为外键关联：

```sql
restaurants.id
```

---

## Restaurant

```java
@OneToMany(mappedBy = "restaurant")
private List<MenuItem> menuItems;
```

含义：

```text
一个 Restaurant
        ↓
拥有
        ↓
多个 MenuItem
```

---

# 2. 学习 mappedBy

第一次深入理解：

```java
@OneToMany(mappedBy = "restaurant")
```

中的：

```java
mappedBy = "restaurant"
```

并不是表名。

而是：

```java
MenuItem 类中的字段名
```

即：

```java
private Restaurant restaurant;
```

JPA 通过：

```text
mappedBy = "restaurant"
```

找到：

```text
MenuItem
    ↓
restaurant字段
    ↓
restaurant_id
```

从而建立双向关系。

## 学习 Spring Data JPA Query Method

第一次接触：

```java
findByRestaurantId(...)
```

这种方法。

虽然没有实现代码：

```java
List<MenuItem> findByRestaurantId(Long restaurantId);
```

Spring Data JPA 会自动生成：

```sql
SELECT *
FROM menu_items
WHERE restaurant_id = ?
```

这是一种约定优于配置的设计思想。

# 6. 深入理解 Controller 与 Service

今天重点理解了：

```text
Controller
≠
Service
```

---

## Controller

负责：

```text
接收请求

获取参数

返回结果
```

例如：

```java
@GetMapping
@PostMapping
@PathVariable
@RequestBody
```

---

## Service

负责：

```text
业务逻辑

规则判断

数据处理
```

例如：

```text
检查餐厅是否存在

创建菜单

计算价格

更新库存
```

---

## Repository

负责：

```text
数据库操作
```

例如：

```java
save()

findById()

findAll()
```

---

最终形成：

```text
Browser

    ↓

Controller

    ↓

Service

    ↓

Repository

    ↓

MySQL
```

# 7. 遇到 Hibernate Lazy Loading 问题

出现：

```text
500 Internal Server Error
```

错误：

```text
ByteBuddyInterceptor

HibernateProxy
```

原因：

```java
@ManyToOne(fetch = FetchType.LAZY)
```

导致：

```text
Restaurant
```

被代理对象替代。

Jackson 在序列化时无法处理代理对象。

---

# 8. 学习 JsonIgnore

解决方案：

```java
@JsonIgnore
@ManyToOne(fetch = FetchType.LAZY)
private Restaurant restaurant;
```

作用：

```text
序列化 JSON 时忽略该字段
```

避免：

```text
Hibernate Proxy
```

报错。

---

# 9. 学习 DTO（最重要）

Day 4 最大收获：

```text
Entity
≠
API Response
```

---

## Entity

负责：

```text
数据库映射
```

例如：

```java
MenuItem
```

包含：

```java
restaurant
createdAt
updatedAt
...
```

---

## DTO

负责：

```text
给前端返回数据
```

创建：

```java
MenuItemResponse
```

只保留：

```java
id
name
description
price
imageUrl
available
```

---

## 转换逻辑

新增：

```java
private MenuItemResponse toResponse(...)
```

负责：

```text
MenuItem
    ↓
MenuItemResponse
```

转换。

---

## 修改 Service

从：

```java
public List<MenuItem>
```

变成：

```java
public List<MenuItemResponse>
```

---

## 修改 Controller

从：

```java
return MenuItem
```

变成：

```java
return MenuItemResponse
```

---

# 10. DTO 的意义

今天理解了软件工程中的一句经典原则：

```text
Never expose Entity directly.
```

原因：

```text
Entity = 数据库模型

DTO = API模型
```

职责不同。
